Definiciones de informática

HTML
Es un lenguaje que se utiliza para crear la estructura de las páginas web. Puedes aprender más en MDN HTML.
CSS
Es un lenguaje que sirve para dar estilo y diseño a las páginas web. Puedes aprender más en MDN CSS.
JavaScript
Es un lenguaje de programación que permite añadir interactividad a las páginas web.
