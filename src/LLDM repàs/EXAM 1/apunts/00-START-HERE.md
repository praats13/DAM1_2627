## How to study each file

1. Open the `.html` file in your browser (double-click it) → see the result.
2. Open the same file in a text editor → read the code and the comments `<!-- like this -->`.
3. Close it. Try to write it again **from memory** in a new file. Check against the original.

Step 3 is the one that makes you pass. Reading is not enough — you must write it.

## The 3 golden rules of HTML (remember these!)

1. **Every tag you open, you close.** `<p>` … `</p>`
2. **Close in reverse order** (like a box inside a box). `<b><i>hi</i></b>` ✅ — `<b><i>hi</b></i>` ❌
3. **Attributes go inside the opening tag, with quotes.** `<td colspan="2">`

If you remember only these 3 rules, you can already find half of the errors in the exam.
